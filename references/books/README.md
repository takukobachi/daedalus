# Books

参考書籍の書誌情報と読書ノート。複数の分析ドキュメントから繰り返し参照される書籍について、
章構成・対象バージョン・Daedalus 内のどのドキュメントがどの章に依拠しているかを 1 か所にまとめる。
書籍本文の転載はせず、各ドキュメントでは要旨を再構成したうえで章・節単位で引用する。

## 索引

- `cited-textbooks.md` — 繰り返し引用される教科書の索引。3 本以上の文書から引用されている
  12 冊 (Hennessy & Patterson、Kleppmann、Åström & Murray、Golub & Van Loan、Sze & Ng ほか) について、
  書誌情報・引用している文書・各文書での用途を分野別にまとめる
- `book-android-internals-arino.md` — 有野和真『Androidを支える技術〈I〉〈II〉』(技術評論社, 2017)。
  Android 7.0 Nougat 時点の GUI システム (Ⅰ巻) と Activity・プロセス管理・起動 (Ⅱ巻) の実装解説。
  `software/android/` の各ドキュメントとの章対応表と、2016 年時点から現在までに古くなった点の読み替えガイド
