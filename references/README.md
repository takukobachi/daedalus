# References

参考資料 (references)。論文・書籍・記事など、分析ドキュメントが依拠する資料の
書誌情報や要約を管理する。

## 運用方針

- 個々の出典は、各分析ドキュメント末尾の「参考文献 / References」セクションに
  引用規約（AGENTS.md の Citations）どおり記載するのが基本。本ディレクトリへの
  登録は必須ではない。
- 複数のドキュメントから繰り返し参照される資料や、要約・読書ノートとして独立した
  価値を持つ資料は、下記の種類別サブディレクトリに置く。
- サブディレクトリは最初の資料を追加するときに作成する（空のプレースホルダは
  置かないという AGENTS.md の規約）。

## Structure

- `papers/` — 学術論文、技術論文
- `books/` — 参考書籍の情報（[索引](books/README.md)）
- `articles/` — オンライン記事、ブログ投稿
