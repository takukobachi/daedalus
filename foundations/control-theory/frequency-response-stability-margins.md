# 周波数応答と安定余裕 (Frequency Response & Stability Margins)

## 概要 (Overview)

制御理論シリーズの第2回。第1回 §7 では、3つの1次遅れからなるループ L(s) = K/(s + 1)³ がゲイン K = 8 で発振し始めることを、特性方程式の代数 (ラウス–フルヴィッツ) で確かめた。同じ回の最後で、その原因は「位相が 180° 遅れる周波数で、ループゲインが 1 以上になること」だと述べた。本回はこの周波数の見方を体系として扱う。

周波数の見方には、代数の見方にない利点が3つある。第一に、**測定できる**。プラントの方程式が分からなくても、正弦波を入れて出力の振幅と位相を測れば周波数応答が得られる。第二に、**むだ時間を正確に扱える**。e^{−sT} は多項式ではないが、周波数応答では「利得 1、位相 −ωT」という単純な形になる。第三に、**どれだけ安定か**を数値で言える。極が左半面にあるかどうかは安定か不安定かの二択しか答えないが、ゲイン余裕・位相余裕・最大感度は、モデル誤差や追加の遅れにどこまで耐えられるかを示す。

本回は (1) 周波数応答とボード線図、(2) ナイキスト安定判別、(3) ゲイン余裕・位相余裕・最大感度、(4) むだ時間と遅れ余裕、(5) ボードの感度積分による設計の限界、(6) ループ整形による補償器設計を扱う。

## 本論 (Main Content)

### 1. 周波数応答とボード線図 (frequency response and Bode plots)

安定な LTI システムに正弦波 sin ωt を入れると、過渡応答が消えた後の出力は同じ周波数の正弦波になる。変わるのは振幅と位相だけであり、それは伝達関数に s = jω を代入した複素数 G(jω) で決まる。

```text
入力 sin ωt  →  定常出力 |G(jω)| · sin(ωt + ∠G(jω))
  利得 (gain):  |G(jω)|、デシベルでは 20 log₁₀|G(jω)| [dB]
  位相 (phase): ∠G(jω)
```

**ボード線図 (Bode plot)** は、横軸に対数目盛の ω をとり、利得 [dB] と位相 [度] を上下2段に描いた図である。対数をとると、伝達関数の積が利得の和になる。そのため、要素ごとの折れ線を足し合わせるだけで全体を描ける (Bode 1945)。

```text
要素             利得の漸近線                         位相
積分 1/s         −20 dB/dec の直線 (ω = 1 で 0 dB)     −90° で一定
1次遅れ 1/(τs+1) 折点 ω = 1/τ まで 0 dB、以降 −20 dB/dec  0° → −90° (折点で −45°)
1次進み (τs+1)   折点以降 +20 dB/dec                   0° → +90°
2次系 (ζ, ω_n)   ω_n 以降 −40 dB/dec。ζ < 0.707 で共振ピーク  0° → −180°
                 ピーク値 M_r = 1/(2ζ√(1 − ζ²))
むだ時間 e^{−sT}  0 dB で一定                           −ωT [rad]。上限なく遅れ続ける
右半面零点 (1 − τs) 利得は (τs+1) と同じ                0° → −90° (進まずに遅れる)
```

最後の2行は、第1回 §3 で応答速度の制約として挙げた2つである。どちらも利得を変えずに位相だけを遅らせる。右半面に零点も極もなく、むだ時間も含まない系を**最小位相系 (minimum phase system)** と呼ぶ。最小位相系では、利得曲線が決まれば位相曲線も決まる。これがボードの利得–位相関係であり、利得の傾きが広い帯域で −20n dB/dec なら、位相はおよそ −90n° になる (Bode 1945)。利得を急に下げようとすると位相も大きく遅れる。§6 のループ整形はこの制約の中で行う。

### 2. ナイキスト安定判別 (the Nyquist stability criterion)

閉ループの極は特性方程式 1 + L(s) = 0 の根である。ナイキスト安定判別は、この根が右半面にいくつあるかを、L(jω) の軌跡 (ナイキスト線図) だけから数える方法である (Nyquist 1932)。根拠は複素関数論の**偏角の原理 (argument principle)** にある。右半面を囲む閉曲線に沿って s を一周させると、1 + L(s) の像が原点のまわりを回る回数は、右半面にある零点の数と極の数の差に等しい。

```text
Z = N + P
  Z: 閉ループの右半面の極の数 (= 1 + L の右半面の零点)。安定には Z = 0 が必要
  P: 開ループ L の右半面の極の数 (既知)
  N: L(jω) の軌跡が点 −1 を時計回りに囲む回数 (ω を −∞ から +∞ まで動かす)

開ループが安定 (P = 0) なら:  閉ループが安定 ⇔ L(jω) の軌跡が −1 を囲まない
```

1 + L の原点まわりの回転は、L の −1 まわりの回転と同じである。そのため **−1 が臨界点**になる。これを第1回の例で確かめる。L(jω) = K/(jω + 1)³ の位相は各極が −arctan ω ずつ寄与するので、位相が −180° になるのは arctan ω = 60°、つまり ω = √3 のときである。このときの利得は K/(√(1 + 3))³ = K/8 になる。軌跡は K < 8 なら −1 の右側を通り、K > 8 なら −1 を囲む。代数で求めた K < 8 と一致する。

ナイキスト判別はラウス–フルヴィッツの判別より手間がかかるが、適用範囲が広い。L(jω) が測定データでも、むだ時間を含んでいても使える。開ループが不安定 (P > 0) な場合も扱える。その場合、安定化には軌跡が −1 を反時計回りに P 回囲む必要がある。

### 3. ゲイン余裕・位相余裕・最大感度 (gain margin, phase margin, maximum sensitivity)

ナイキスト線図が −1 を囲まなくても、すれすれを通るなら少しのモデル誤差で不安定になる。安定余裕は、軌跡が −1 からどれだけ離れているかを測る。

```text
位相交差周波数 ω_pc: ∠L(jω_pc) = −180°
ゲイン交差周波数 ω_gc: |L(jω_gc)| = 1 (0 dB)

ゲイン余裕 (gain margin):   GM = 1 / |L(jω_pc)|      — あと何倍ゲインを上げると不安定か
位相余裕 (phase margin):    PM = 180° + ∠L(jω_gc)   — あと何度位相が遅れると不安定か
最大感度 (max. sensitivity): M_s = max_ω |S(jω)| = 1 / (−1 から軌跡までの最短距離)
   M_s から下限が決まる: GM ≥ M_s/(M_s − 1),  PM ≥ 2 arcsin(1/(2M_s))
```

L(s) = K/(s + 1)³ で数値を比べる。

```text
K = 2: ω_pc = √3 ≈ 1.73, |L| = 0.25 → GM = 4 (12 dB)
       ω_gc ≈ 0.77, ∠L ≈ −112.4° → PM ≈ 67.6°
       M_s ≈ 1.67
K = 4: GM = 2 (6 dB)
       ω_gc ≈ 1.23, ∠L ≈ −152.9° → PM ≈ 27.1°
       M_s ≈ 3.0
```

K = 4 のゲイン余裕 6 dB は、よく使われる目安 (6 dB 以上) をちょうど満たす。しかし位相余裕は 27° しかなく、最大感度は 3 に達する。この状態では、ある周波数の外乱が閉ループで 3 倍に増幅され、ステップ応答は大きく振動する。GM と PM はそれぞれナイキスト線図上の1点しか見ていない。軌跡がその2点の間で −1 に近づく場合、どちらの指標もそれを捉えられない。M_s は軌跡全体の −1 までの最短距離なので、1つの数で両方の余裕を下から保証できる。実務の目安は、PM が 30〜60°、GM が 6 dB 以上 (Ogata 2010)、M_s が 1.2〜2 程度である (Åström & Murray 2021)。

位相余裕は閉ループの減衰と直結する。閉ループが2次系で近似できる範囲では、減衰比はおよそ ζ ≈ PM/100 になる (PM を度で表す。おおむね PM ≤ 60° で成り立つ近似; Franklin et al. 2019)。PM 30° の系は ζ ≈ 0.3 で、第1回 §5 の式からオーバーシュートは約 37% になる。

### 4. むだ時間と遅れ余裕 (time delay and delay margin)

むだ時間は利得を変えず、ゲイン交差周波数での位相を ω_gc·T [rad] だけ遅らせる。したがって、ループが耐えられる追加のむだ時間 (**遅れ余裕, delay margin**) は位相余裕から直接求まる。

```text
遅れ余裕 T_dm = PM [rad] / ω_gc

K = 2 の例: PM ≈ 67.6° ≈ 1.18 rad, ω_gc ≈ 0.77 rad/s → T_dm ≈ 1.54 s
K = 4 の例: PM ≈ 27.1° ≈ 0.47 rad, ω_gc ≈ 1.23 rad/s → T_dm ≈ 0.38 s
```

ゲインを2倍にすると、耐えられる遅れは約 1/4 になる。ゲインを上げると交差周波数が上がり、同時に位相余裕が減るからである。この関係を逆に読むと、むだ時間 T を持つループでは、ゲイン交差周波数を 1/T よりかなり低く抑えなければならない。**むだ時間がループの帯域の上限を決める。**

むだ時間の発生源は、目に見える輸送遅れだけではない。計算機制御ではサンプリング周期 h の零次ホールドが平均 h/2 の遅れになり、計算時間と通信遅延がそれに加わる。周期のばらつき (ジッタ) も実効的な遅れとして位相余裕を削る (Åström & Wittenmark 1997)。メトリクスの集計窓、ログの収集間隔、インスタンスの起動時間のようなソフトウェアの遅れも、ループの中にあれば同じ扱いになる。

### 5. ボードの感度積分と設計の限界 (Bode's sensitivity integral)

第1回 §4 では、同じ周波数で S と T を両方小さくできないことを見た。ボードの感度積分は、さらに強い制約を課す。周波数の全域で見ても、S を小さくできる量には上限がある。

```text
ループ L の相対次数が 2 以上 (分母の次数 − 分子の次数 ≥ 2) のとき:

  ∫₀^∞ ln|S(jω)| dω = π Σ Re(p_k)
  p_k: 開ループ L の右半面の極

開ループが安定なら右辺は 0
```

ln|S| < 0 の周波数では外乱が抑えられ、ln|S| > 0 の周波数では増幅される。開ループが安定なら、抑えた分の面積と増幅した分の面積が等しい。低周波で外乱を強く抑えるほど、どこか別の周波数で増幅が起きる。押すと別の場所が盛り上がるウォーターベッドにたとえて、これを**ウォーターベッド効果 (waterbed effect)** と呼ぶ。帯域が限られていると、増幅は狭い周波数範囲に集まり、高いピーク (大きな M_s) になる。

開ループが不安定な場合、右辺は正になり、増幅の面積が抑制の面積を上回る。不安定な極が右に遠いほど、この差は大きい。Stein (2003) は、倒立振子と前進翼の実験機 X-29 を例にこの制約を論じ、不安定なプラントを制御する難しさを「不安定を敬え (respect the unstable)」と表現した。同じ講演で、チェルノブイリ原発事故も不安定な系への敬意を欠いた例として挙げている。右半面の極を持つプラントを安定化するには、制御器の作り方によらず、一定以上の帯域とアクチュエータの能力が必要になる。

### 6. ループ整形と補償器 (loop shaping and compensators)

§1〜§5 をまとめると、良いループ伝達関数 L(jω) の形が決まる (Åström & Murray 2021)。

```text
低周波:     |L| を大きく      → 追従・外乱抑制・プラント変動への鈍感さ (S ≈ 0)
交差周波数: 傾き約 −20 dB/dec → 利得–位相関係により位相 ≈ −90°、十分な PM
高周波:     |L| を急に下げる   → 雑音とモデル誤差の遮断 (T ≈ 0)
交差周波数の上限: むだ時間・右半面零点・アクチュエータの飽和が決める
交差周波数の下限: 右半面の極 (§5) が決める
```

**ループ整形 (loop shaping)** は、プラント P の周波数応答に補償器 C を掛け、L = PC をこの形に近づける設計法である。基本の部品は3つある。

- **進み補償 (lead compensator)**: (1 + sαT)/(1 + sT) (α > 1)。ゲイン交差付近で位相を進め、位相余裕を稼ぐ。PID の微分項に当たる働きで、同じように高周波の雑音を増幅する。
- **遅れ補償 (lag compensator) と積分**: 低周波の利得だけを持ち上げ、定常偏差を減らす。交差周波数より十分低い位置に置けば、位相余裕をあまり削らない。PI 制御の積分項はその極限 (折点を ω = 0 に置いたもの) である。
- **ノッチフィルタ (notch filter)**: 狭い周波数帯だけ利得を落とす。ロボットアームの減速機やロケット機体の曲げのような、軽く減衰した構造共振を交差周波数より上で抑えるのに使う。共振のピークが 0 dB を超えると、そこで新たなゲイン交差が生じて不安定になりうるためである。

PID 制御器の周波数応答は、積分 (低周波で −20 dB/dec)、比例 (平坦)、微分 (高周波で +20 dB/dec) を組み合わせた形をしている。第1回の Ziegler–Nichols 法の調整は、ループ整形の観点では限界ゲイン K_u と周期 T_u という位相交差点の情報だけを使う設計に当たる。

## 工学への接続 (Engineering Connections)

- **オペアンプの位相補償**: 開ループ利得が大きく、内部に複数の極を持つオペアンプは、そのままでは負帰還をかけると発振しうる。汎用品はチップ内のコンデンサで1つの極を極端に低い周波数へ移し (支配極補償)、利得 1 の帰還でも位相余裕が残るようにしている。§6 の「交差周波数で傾き −20 dB/dec」を IC の内部で作り込んだ例である。
- **PLL・CDR のジッタ規格**: CDR のジッタ転送特性は閉ループの T(jω) そのものであり、規格が制限するジッタ転送のピーキングは |T| の共振ピーク、つまり位相余裕の不足を表す。
- **系統連系インバータの安定性**: 短絡比の小さい弱い系統では、系統のインピーダンスがインバータの電流制御と PLL のループ伝達関数に入り込み、位相余裕を削って発振を起こしうる。インピーダンスに基づく安定解析は、ナイキスト判別を系統とインバータの間に適用したものである。
- **燃焼不安定とレイリー基準**: 熱発生の揺らぎと圧力振動の位相関係で増幅か減衰かが決まるという条件は、§2 の位相条件を音響系と燃焼の結合ループに適用したものと読める。「位相をずらす」対策は、ループの位相を臨界点から遠ざける操作に当たる。
- **キュー管理と輻輳制御**: 送信レートの調整は RTT 分のむだ時間を持つフィードバックループであり、RED 型の AQM が RTT やフロー数の条件によって振動しうることは、制御理論のモデルで解析されている (Hollot et al. 2001)。遅延そのものを制御量にする CoDel の設計も、§4 の「遅れがループを律する」という見方で読める。
