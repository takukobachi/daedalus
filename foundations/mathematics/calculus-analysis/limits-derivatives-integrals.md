# 極限・微分・積分 (Limits, Derivatives, and Integrals)

## 概要 (Overview)

微分積分・解析シリーズの第1回。微分積分は「変化(微分)と蓄積(積分)を扱う数学」であり、物理学のほぼすべての法則は微分方程式(変化の規則)として書かれる。電磁気学シリーズで既に `dΦ/dt`(ファラデーの法則)や `∮E·dl`(周回積分)が現れているように、Daedalus の物理系文書は本回の言葉を暗黙の前提にしている。その前提を明示的に埋めるのが本回の役割である。

積み上げる順序は: (1) 極限(「限りなく近づく」の厳密化)、(2) 微分(**最良の線形近似**という視点)、(3) テイラー展開(線形近似の高次への延長)、(4) 積分と**微積分学の基本定理**(微分と積分が互いの逆演算であるという中心定理)、(5) 指数関数(微分方程式の世界の主役)。理論の細部より「工学で実際に使われる形」(線形化、小角近似、収束判定)との接続を優先する。

## 本論 (Main Content)

### 1. 極限と連続 (limits and continuity)

数列 aₙ が L に**収束する**とは、任意の許容誤差 ε > 0 に対し、ある番号から先はすべて `|aₙ − L| < ε` となること (Spivak 2008, Ch. 5)。「限りなく近づく」という直観を、**誤差の要求 ε と、それを満たす条件の存在**という検証可能な形に置き換えたのがこの定義であり、解析学の厳密さはすべてここから始まる。関数の極限・連続も同型で、連続とは `x → a` のとき `f(x) → f(a)` となること、つまり入力の微小な変化が出力の微小な変化しか生まないことである。

工学的に重要なのは、この定義が**打ち切り誤差の管理**の原型だということ: 反復法(Newton 法、勾配法、電力潮流計算)は「収束列を有限で打ち切って ε 精度の近似を得る」操作であり、収束の定義がそのまま停止条件の設計図になる。

### 2. 微分 = 最良の線形近似 (derivative as best linear approximation)

微分係数の定義は差分商の極限だが、本質は**近似**の言葉で読むのがよい。

```text
f'(a) = lim_{h→0} [f(a+h) − f(a)] / h

⟺  f(a+h) = f(a) + f'(a)·h + o(h)   (誤差 o(h) は h より速く 0 になる)
```

つまり微分とは「曲がった関数 f を、点 a の近くで**傾き f'(a) の直線で置き換える**とき、その置き換えが h → 0 で相対的に完璧になる」ことの主張である (Apostol 1967, Ch. 4)。合成関数の連鎖律 `(f∘g)' = f'(g(x))·g'(x)` は「線形近似の合成は傾きの積」と読め、これが多変数に一般化されるとヤコビアン(線形代数の行列)の積になる。「微分は局所的に線形代数」という構図がここで確立する。

導関数の符号は増減を、2階導関数は凸性を与え、`f'(x) = 0` が極値の必要条件になる。**最適化とは導関数の零点探しである**。機械学習の勾配降下法はこの一文の大規模化に他ならない。

### 3. テイラー展開 (Taylor expansion)

線形近似を高次に延長すると、滑らかな関数は点 a のまわりで多項式によって系統的に近似できる。

```text
f(a+h) = f(a) + f'(a)h + f''(a)/2!·h² + ⋯ + f⁽ⁿ⁾(a)/n!·hⁿ + Rₙ
剰余項: Rₙ = f⁽ⁿ⁺¹⁾(ξ)/(n+1)!·hⁿ⁺¹  (ξ は a と a+h の間のある点)
```

剰余項(ラグランジュ形)が**誤差の上界を陽に与える**ことが工学的価値の核心である (Apostol 1967, Ch. 7)。代表例を示す。

```text
sin x ≈ x − x³/6        cos x ≈ 1 − x²/2        e^x ≈ 1 + x + x²/2
(1+x)ⁿ ≈ 1 + nx  (|x| ≪ 1)
```

物理・工学の「小角近似」「平衡点近傍の微小変位」「振り子は単振動」はすべてテイラー展開の1〜2次打ち切りであり、非線形な世界が平衡点の近くでは線形に見えること(線形代数と微分方程式が工学の共通言語である理由)の数学的根拠がここにある。数値計算では、数学関数ライブラリ (libm) の sin/exp/log の実装が、引数を縮約した上での多項式近似(テイラー/チェビシェフ系)として組まれ、剰余項の評価が「最終ビットまでの精度保証」を支える。

### 4. 積分と微積分学の基本定理 (integrals and the fundamental theorem)

定積分 `∫ₐᵇ f(x)dx` は区間を細分した短冊和(リーマン和)の極限であり、「蓄積量」の厳密化である。独立に定義された微分と積分を結ぶのが**微積分学の基本定理 (fundamental theorem of calculus)** である。

```text
F(x) = ∫ₐˣ f(t)dt  ⟹  F'(x) = f(x)     (蓄積の変化率 = 被積分関数)
∫ₐᵇ f(x)dx = F(b) − F(a)   (F は f の任意の原始関数)
```

「変化率を知っていれば蓄積が分かり、蓄積を知っていれば変化率が分かる」という双対が、電流(電荷の変化率)と電荷、速度と位置、電力とエネルギーのように、物理量のペアを系統的に生む (Spivak 2008, Ch. 14)。数値的には、閉形式の原始関数を持たない積分(正規分布の累積分布関数が代表)が普通に存在するため、台形則・シンプソン則などの**数値積分**が必要になり、その誤差評価はやはりテイラー展開から導かれる。

### 5. 指数関数と微分方程式への入口 (e^x and the gateway to ODEs)

指数関数 `e^x` は「微分しても変わらない」性質 `(e^x)' = e^x` で特徴づけられる。このため、**変化率が現在量に比例する**系はすべて指数関数で解ける。

```text
dy/dt = ky   ⟹   y(t) = y(0)·e^{kt}
k < 0: 指数減衰 — RC 放電 (時定数 τ = RC)、放射性崩壊、キャッシュの TTL
k > 0: 指数成長 — 発振の立ち上がり、複利、正帰還
```

「時定数 τ の1倍で 63%、5倍でほぼ完了 (99.3%)」という回路の経験則は `1 − e^{−t/τ}` の値そのものである。さらに `e^{iθ} = cos θ + i sin θ`(オイラーの公式)によって指数関数は振動をも表現し、交流回路・波動・フーリエ解析の記法の基盤になる。微分方程式の系統的な解法と2階系(振動子・RLC)は次回に扱う。

## 工学への接続 (Engineering Connections)

- **線形化 (linearization)**: トランジスタの小信号モデル、制御系の平衡点まわりの線形化、電力潮流の Newton 法など、「動作点でテイラー展開して1次で打ち切る」操作は、非線形システムを線形代数の道具(固有値・行列分解)に接続する、工学で最も使われる数学的操作である。
- **Newton 法**: `f(x) = 0` を「現在の推定点で線形近似して、その零点へ跳ぶ」を反復する。収束すれば誤差が2乗で縮む(2次収束)。テイラー展開の2次剰余項がその証明を与える。回路シミュレータ・潮流計算・最適化ソルバの内側で毎日動いている。
- **数値微分と丸め誤差の綱引き**: 差分近似 `[f(x+h) − f(x)]/h` の誤差は、打ち切り誤差 O(h) と丸め誤差 O(u/h) の和になり、h を小さくしすぎると悪化する。微積分(打ち切り)と浮動小数点(丸め、線形代数第4回)が同じ式の中で出会う代表例である。
- **積分 = センサ融合の蓄積**: 慣性航法は加速度を2回積分して位置を得るが、バイアス誤差も2回積分されて t² で成長する。「積分は誤差も蓄積する」ことが、GNSS など外部参照との融合が必須になる理由を説明する。
