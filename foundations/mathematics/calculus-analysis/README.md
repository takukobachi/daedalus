# 微分積分・解析 (Calculus & Analysis)

変化と蓄積の数学。それ自体が単独の応用に直結するというより、物理学シリーズ
全体(力学・電磁気学・熱力学)、制御理論、最適化の**前提言語**として機能する。
「微分方程式が読める」状態を作ることがこのシリーズの目標である。

## 文書一覧 (Documents)

1. [`limits-derivatives-integrals.md`](limits-derivatives-integrals.md) —
   極限と連続、微分(定義・線形近似・テイラー展開)、積分と微積分学の基本定理、
   指数関数 e^x の特別な役割。シリーズの起点
2. [`ordinary-differential-equations.md`](ordinary-differential-equations.md) —
   1階線形 (RC と時定数)、2階線形 (振動・減衰・共振、RLC と機械系のアナロジー)、
   連立系の安定性(線形代数の固有値と合流)、数値解法と硬い方程式。
   物理学シリーズの方程式を「解ける」ようにする回

3. [`multivariable-calculus.md`](multivariable-calculus.md) —
   偏微分・勾配・ヤコビアン、連鎖律と誤差逆伝播、ヘッセ行列と最適化の幾何、
   発散・回転、ガウス・ストークスの積分定理とマクスウェル方程式の微分形。
   シリーズ最終回

当初計画した3本のシリーズはこれで完結。以降のテーマ(複素解析、偏微分方程式、
変分法など)は必要が生じた時点でロードマップを再開する。
