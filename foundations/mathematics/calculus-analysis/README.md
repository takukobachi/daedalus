# 微分積分・解析 (Calculus & Analysis)

変化と蓄積の数学。それ自体が単独の応用に直結するというより、物理学シリーズ
全体(力学・電磁気学・熱力学)、制御理論、最適化の**前提言語**として機能する。
「微分方程式が読める」状態を作ることがこのシリーズの目標である。
