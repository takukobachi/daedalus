# 固有値・固有ベクトルと対角化 (Eigenvalues, Eigenvectors, and Diagonalization)

## 概要 (Overview)

線形代数シリーズの第2回。線形写像を繰り返し適用したとき——反復法の収束、マルコフ連鎖の遷移、力学系の時間発展、制御ループの応答——系がどこへ向かうかを支配するのは、写像が**向きを変えないで伸縮だけする方向**、すなわち**固有ベクトル (eigenvector)** と、その伸縮率**固有値 (eigenvalue)** である。

本ドキュメントは、固有値・固有ベクトルの定義から**対角化 (diagonalization)**——「良い基底を選べば線形写像はただの成分ごとの伸縮になる」——までを積み上げ、応用側の共通パターンである「行列の冪 (power) の挙動は最大固有値が決める」を導く。前回の「行列=基底を固定した線形写像の表現」という視点の、最初の本格的な配当である: 表現が基底の選び方次第なら、**最も見通しの良い基底を選べばよい**。

## 本論 (Main Content)

### 1. 固有値と固有ベクトル (eigenvalues and eigenvectors)

正方行列(=同じ空間への線形写像)`A: ℝⁿ → ℝⁿ` に対し、

```text
Av = λv,   v ≠ 0
```

を満たすスカラー λ を**固有値 (eigenvalue)**、v を**固有ベクトル (eigenvector)** と呼ぶ。幾何的には「A で写しても向きが変わらず、λ 倍に伸縮するだけの方向」である(λ < 0 は反転、複素 λ は回転を含む)。

定義を移項すると `(A − λI)v = 0, v ≠ 0`、つまり **λ が固有値であることと、A − λI の核が自明でない(=A − λI が可逆でない)ことは同値**である (Axler 2024, §5.A)。前回の「核・像・可逆性」の言葉がそのまま判定条件になっている。

計算上は、可逆性の判定量である**行列式 (determinant)** を使い、**特性多項式 (characteristic polynomial)** の根として求める:

```text
det(A − λI) = 0    (n次多項式 → 重複を込めて n 個の根)
```

行列式は「線形写像が体積を何倍にするか」を表すスカラーで、ゼロであることと写像が空間を潰す(=可逆でない)ことが同値になる。その代数的性質の詳細は行列分解の回(ロードマップ4)に譲り、本ドキュメントでは可逆性の判定量として使う。

### 2. 対角化 (diagonalization)

n×n 行列 A が n 本の線形独立な固有ベクトル `v₁, …, vₙ`(固有値 `λ₁, …, λₙ`)を持つとき、固有ベクトルを列に並べた行列 P と固有値を対角に並べた**対角行列 (diagonal matrix)** D により

```text
A = P D P⁻¹        D = diag(λ₁, …, λₙ)
```

と書ける。これが**対角化 (diagonalization)** である。意味は表現論的に読むのが正しい: **固有ベクトルを基底に取り直せば、A という写像は「各座標を λᵢ 倍する」だけの演算になる**。P⁻¹ が「固有基底への座標変換」、D が「本体(成分ごとの伸縮)」、P が「元の基底へ戻す変換」である。

最大の配当は行列の冪が自明になることである:

```text
Aᵏ = P Dᵏ P⁻¹ = P diag(λ₁ᵏ, …, λₙᵏ) P⁻¹
```

素朴に計算すれば行列積 k−1 回(各 O(n³))の反復が、対角化後は**スカラーの冪乗**に落ちる。漸化式・差分方程式・微分方程式系の解が「固有値の指数関数の重ね合わせ」になるのはこの式の直接の帰結であり、次の定性的判定則を与える:

- **|λ| < 1(全固有値)** → Aᵏ は 0 に収束(系は安定・減衰する)
- **|λ| > 1 がある** → その固有方向の成分が指数的に発散する
- **最大の |λ|(スペクトル半径, spectral radius)が挙動を支配し、収束の速さは2番目との比で決まる**

反復解法の収束判定、制御系の安定判別、マルコフ連鎖の混合の速さは、すべてこの3行の言い換えである。

なお、すべての行列が対角化可能なわけではない(固有ベクトルが n 本に足りない**欠陥 (defective)** 行列が存在する)。一般の行列の標準形(ジョルダン標準形)と、対角化を諦めて数値的に固有値を求める方法は後続回で扱う。

### 3. 対称行列とスペクトル定理 (symmetric matrices and the spectral theorem)

実**対称行列 (symmetric matrix)** `A = Aᵀ` は例外的に行儀が良い。**スペクトル定理 (spectral theorem)** (Axler 2024, §7.B) により:

1. 固有値はすべて実数
2. 異なる固有値の固有ベクトルは直交する
3. **正規直交基底を固有ベクトルだけで組める**(P を直交行列にでき、`A = QDQᵀ`)

つまり対称行列は「直交する主軸に沿った純粋な伸縮」であり、回転成分もせん断もない。共分散行列・グラフのラプラシアン・二次形式のヘッセ行列など、応用に現れる行列の多くが対称なのは偶然ではなく、「対 (pair) の上に定義された量」が自然に対称性を持つためである。全固有値が正である対称行列を**正定値 (positive definite)** と呼び、最適化(凸性判定)と数値解法(コレスキー分解)の前提条件として繰り返し登場する。

### 4. 確率行列と定常分布 (stochastic matrices and stationary distributions)

各列が非負で列和が1の行列(**確率行列, stochastic matrix**)は、マルコフ連鎖 (Markov chain) の1ステップ遷移を表す。状態分布ベクトル x に対し、k ステップ後の分布は `Aᵏx` ——まさに§2の行列の冪である。確率行列は必ず固有値 1 を持ち、**ペロン・フロベニウスの定理 (Perron–Frobenius theorem)** の条件下(既約・非周期)でそれが唯一の最大固有値となり、対応する固有ベクトルが**定常分布 (stationary distribution)** を与える (Strang 2016, §10.3)。「どこから始めても同じ分布に収束し、収束の速さは第2固有値で決まる」——PageRank も、キュー・信頼性モデルの定常解析も、この一つの構造の実例である。

## 工学への接続 (Engineering Connections)

- **反復の漸近挙動の言語**: 「この処理を無限に繰り返すとどうなるか」という問いは、工学の随所で「スペクトル半径は1より小さいか」に翻訳される。数値反復解法の収束、フィードバック制御の安定性、待ち行列の定常性が同じ数学に落ちる。
- **主軸への分解**: スペクトル定理の「直交主軸+伸縮」は、データの主成分分析 (PCA)、構造物・回路の振動モード解析、電力系統の動揺モード解析に共通する分解の骨格である。
- **物理との接続**: 量子力学では観測可能量が(対称行列の複素版である)エルミート作用素で表され、測定値はその固有値、エネルギー準位はハミルトニアンの固有値である。ロードマップ上の量子力学・固体物理の回で、本ドキュメントが直接の前提になる。
