# 数論・代数 (Number Theory & Algebra)

整数と有限構造の代数。機械整数のラップアラウンド (mod 2⁶⁴) から、CRC・スクランブラ・
AES・Reed–Solomon を支える有限体、そして TLS・セキュアブートの公開鍵暗号まで、
「余りの世界の算術」を基礎から積み上げる3回シリーズ。シリーズ全体を通じた主題は2つある。
1つは、有限体の演算が**丸め誤差のない厳密な線形代数**を与えること。もう1つは、冪乗の
**順方向は対数時間・逆方向は困難**という非対称が公開鍵暗号の存在根拠であること。困難性は証明ではなく
「最良の既知攻撃」への賭けであり、鍵長の推移と耐量子移行はその賭け金の改定として読む。
