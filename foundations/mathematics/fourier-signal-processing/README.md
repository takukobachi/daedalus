# フーリエ解析・信号処理 (Fourier Analysis & Signal Processing)

信号を正弦波の重ね合わせとして読む数学。時間領域と周波数領域の往復により、
帯域幅・フィルタ・スペクトルという工学の日常語に厳密な意味を与える。無線
(OFDM)、オーディオ、ディスプレイ、高速シリアルリンク (SerDes) の分析文書が
暗黙に使っている「エッジ = 高周波」「イコライゼーション = 逆フィルタ」の
数学的基盤を明示的に埋めることがこのシリーズの目標である。

## 文書一覧 (Documents)

1. [`fourier-series-transform.md`](fourier-series-transform.md) —
   フーリエ級数(直交基底への射影、方形波と無限帯域)、フーリエ変換
   (スペクトル、主要変換対、時間・周波数の双対性と不確定性関係)、
   畳み込み定理と LTI システム(周波数応答、フィルタ、逆フィルタとしての
   イコライゼーション)、デルタ関数と「エッジ = 高周波」の直観。シリーズの起点
2. [`sampling-dft-fft.md`](sampling-dft-fft.md) —
   サンプリング定理(インパルス列とスペクトルの複製、ナイキスト周波数、
   sinc 補間による再構成)、エイリアシング(折り返し、アンチエイリアシング
   フィルタ、帯域通過サンプリング)、量子化(6 dB/bit 則、ディザ、
   オーバーサンプリングと ΔΣ)、DFT(スペクトル漏れと窓関数、分解能と
   記録長)、FFT(バタフライと O(N log N)、OFDM の経済性)。ADC/DAC を
   物理世界と計算の橋として位置づける回
