# 量子力学・固体物理 (Quantum Mechanics & Solid-State Physics)

トランジスタ・メモリ・イメージセンサ・原子時計の動作原理を支える物理。
「なぜシリコンで計算機が作れるのか」に、電子の量子的性質から
バンド理論・半導体デバイスまで積み上げて答えることがこのシリーズの目標である。

## 文書一覧 (Documents)

1. [`band-theory-semiconductors.md`](band-theory-semiconductors.md) —
   量子力学の最小限(エネルギー量子化、電子の波動性、パウリの排他原理)、
   バンド構造の形成、導体・絶縁体・半導体の区別、電子と正孔、ドーピング。
   シリーズの起点
2. [`pn-junction-diode.md`](pn-junction-diode.md) —
   ドリフトと拡散、空乏層と内蔵電位(フェルミ準位の整合とバンドの曲がり)、
   ダイオード方程式と整流、降伏(なだれ・ツェナー)、フォトダイオードと LED。
   すべての半導体デバイスの基本構造

3. [`mosfet-cmos.md`](mosfet-cmos.md) —
   MOS 構造と反転層、しきい値電圧、I-V 特性、CMOS 相補対と静的電力ゼロ、
   電力の3成分とデナードスケーリングの終焉、FinFET/GAA への構造進化。
   デジタル回路の物理的実体

4. [`tunneling-nonvolatile-memory.md`](tunneling-nonvolatile-memory.md) —
   量子トンネリングと指数的厚さ依存、直接/FN トンネリング、
   フローティングゲートとチャージトラップ (3D NAND)、多値化と V_th 分布、
   P/E 摩耗とデータ保持。NAND フラッシュの書き込み・消去・摩耗の物理
5. [`optoelectronics.md`](optoelectronics.md) —
   吸収・自然放出・誘導放出、直接/間接遷移と「受光は Si、発光は化合物」、
   フォトダイオードとショットノイズ、LED とヘテロ構造、半導体レーザー、
   光通信とシリコンフォトニクス。シリーズ最終回

当初計画した5本のシリーズはこれで完結。以降のテーマ(量子コンピューティングの
デバイス物理、スピントロニクス、熱電変換など)は必要が生じた時点で
ロードマップを再開する。
