# ニュートンの法則と振動 (Newton's Laws and Oscillations)

## 概要 (Overview)

古典力学シリーズの第1回。ロボット・ロケット・自動車の制御ループが操作しているのは、電子でもソフトウェアでもなく、最終的には**質量をもつ物体の運動**である——制御工学が「プラント (plant)」と呼ぶものの正体は、多くの場合ニュートン力学の運動方程式にほかならない。フィードバック則がどれほど洗練されても、それが作用する相手の物理を知らなければ、ゲインの意味も不安定化の理由も語れない。本シリーズは、Daedalus のロボティクス・航空宇宙・車載の分析群が暗黙に依拠している「プラント側の物理」を、基礎から積み上げて文書化する。

本回はその土台を5本の柱で立てる。(1) **ニュートンの三法則**——力学の公理系と、F = ma が「状態の未来を一意に決める2階の微分方程式」であること。そして法則が成り立つ舞台(慣性系)と、モデル化という行為(自由体図)。(2) **運動量とエネルギー**——対称性が生む保存則が、微分方程式を解かずに答えへ跳ぶ「計算の近道」であること。可変質量への適用がロケット方程式を与える。(3) **回転運動と剛体**——トルク・角運動量・慣性モーメントという並進の相似形と、ジャイロ効果・リアクションホイールの物理。(4) **単振動・減衰・共振**——あらゆる安定平衡のまわりに現れる普遍の2階系。RLC 回路と同じ方程式であるため、解析は数学シリーズの ODE 文書に接続するだけでよい。(5) **振り子と安定性**——非線形系を平衡点で線形化し、安定・不安定を固有値で読む標準手順。その不安定側の代表**倒立振子**が、セグウェイからヒューマノイドの直立・ロケットの垂直着陸まで、現代制御の看板問題になっていることを見る。

## 本論 (Main Content)

### 1. ニュートンの三法則と運動方程式 (Newton's laws and the equation of motion)

力学は3つの法則を公理として立つ (Kleppner & Kolenkow 2014, Ch. 2)。

```text
第1法則: 力を受けない物体は等速直線運動を続ける — 慣性系の存在宣言
第2法則: F = dp/dt = ma (質量一定のとき) — 運動の法則
第3法則: 作用があれば同じ大きさで逆向きの反作用がある — F_AB = −F_BA
```

第2法則は数学的には**2階の常微分方程式 (ODE)** である——`m·d²x/dt² = F(x, dx/dt, t)`。解の存在と一意性(ODE 文書 §1)により、**位置と速度の組 (x, v) を初期条件として与えれば未来は一意に決まる**。制御工学が状態変数を「位置と速度」に取るのは慣習ではなく、この定理が「それだけで十分」と保証しているからである。第1法則は自明の繰り返しではなく、**慣性系 (inertial frame)** ——第2法則がそのままの形で成り立つ座標系——が存在するという主張である。加速する座標系(旋回する車、回転する地球)で力学を書くと、実体のない**見かけの力 (fictitious force)** ——遠心力・コリオリ力——を補正項として足す必要がある。IMU(加速度計・ジャイロ)が測るのは慣性系に対する加速度・角速度であり、慣性航法とはこの補正を引き受けて積分する計算にほかならない。

そして力学の実務は方程式を解く前の**モデル化**にある。**自由体図 (free-body diagram)** ——対象を1つ切り出し、外から作用する力を全部矢印で描き尽くす図——は、「系の境界をどこに引くか」「何を無視するか」を強制的に明示させる装置である。張力・垂直抗力・摩擦を数え落とせば、以後の数学がどれほど正確でも答えは間違う。第3法則はこのとき境界の引き方と連動する——内力は対で相殺するため、系を大きく取るほど式から消える。これが次節の保存則の伏線である。

### 2. 運動量とエネルギー — 保存則という近道 (momentum, energy, and conservation laws)

第2法則と第3法則を組み合わせると、多体系の内力は相殺し、**全運動量 (momentum)** の変化は外力だけで決まる。

```text
p = Σmᵢvᵢ,  dp/dt = F_ext  ⟹  F_ext = 0 なら p は保存
仕事-エネルギー定理: ΔK = ∫F·dx,  K = ½mv²
保存力 F = −∇U ⟹ 力学的エネルギー E = K + U が保存 (重力: U = mgh, ばね: U = ½kx²)
```

保存則の工学的価値は**微分方程式を解かずに初状態と終状態を直結できる**ことにある——軌道の詳細(途中でどう動いたか)を全部積分する代わりに、保存量の収支だけで答えが出る。衝突が典型である: 衝突中の力は複雑で測れないが、運動量保存は常に成り立ち、**弾性衝突 (elastic collision)** なら運動エネルギーも保存、**非弾性衝突**では運動エネルギーの一部が変形・熱に落ちる(エネルギーは消えず劣化する——熱力学シリーズ §2 の言葉で言えば品位が下がる)。自動車の衝突安全設計は「運動量は保存させつつ、運動エネルギーをクラッシャブルゾーンの変形で意図的に散逸させる」設計であり、逆に回生ブレーキは K を熱に捨てずに電気として回収する試みである。

保存則の最も美しい応用が**ロケット方程式**である。ロケットは「押す地面」を持たない——推進剤を後方へ投げ、その反作用(運動量保存)で加速する。質量が変わる系に運動量保存を微小時間で適用すると次式を得る。

```text
m·dv = −v_e·dm  (v_e: 排気速度)  ⟹  Δv = v_e·ln(m₀/m_f)   — ツィオルコフスキーの式
   m₀: 初期質量, m_f: 最終質量, v_e = Isp·g₀
```

対数がすべてを支配する——Δv を稼ぐには質量比 m₀/m_f を指数的に増やすしかなく、これが多段ロケットの動機であり、Δv が宇宙機設計の通貨になる理由である(`hardware/aerospace/orbital-mechanics.md` がこの式の上に Δv 収支を組み立てる)。

### 3. 回転運動と剛体 (rotation and rigid bodies)

大きさをもつ物体——**剛体 (rigid body)**、変形を無視できる質点の集まり——の運動は、重心の並進と重心まわりの回転に分解できる。回転側の力学は、並進の各量を外積で作った相似形で書ける。

```text
トルク:      τ = r × F        角運動量: L = r × p,  剛体では L = Iω (主軸まわり)
回転の第2法則: τ = dL/dt
慣性モーメント: I = Σ mᵢrᵢ²   — 回転軸まわりの質量分布の第2モーメント
対応: F ↔ τ,  m ↔ I,  v ↔ ω,  p ↔ L,  K = ½mv² ↔ ½Iω²
```

**慣性モーメント (moment of inertia)** は「回転させにくさ」だが、質量と違い**軸の取り方と質量分布に依存する**——同じ質量でも軸から遠くに分布するほど I は大きい(フライホイールが縁に質量を集める理由)。ロボットアームでは、リンクを伸ばすと手先質量の r が増えて I が肩関節から見て激変する——後続回で扱うマニピュレータ方程式の慣性行列 M(q) が「姿勢 q に依存する」ことの物理的中身はこれである。

外部トルクがなければ L は保存する。この単純な事実が2つの重要現象を生む。第一に**ジャイロ効果 (gyroscopic effect)**: 高速回転する物体に軸を倒すトルクを加えると、軸は倒れずにトルクと直交する方向へ**歳差運動 (precession)** する——dL/dt = τ により、L の変化はトルクの方向に起きるからである。回転する L が姿勢の「硬さ」として働くため、ジャイロは姿勢の基準になり、自転する弾丸・フリスビーは安定する。第二に**内部トルクによる姿勢制御**: 宇宙機は真空中で押す相手がないが、内部の**リアクションホイール (reaction wheel)** を回せば、角運動量保存により機体は逆向きに回る——推進剤を使わない姿勢制御であり、蓄積した角運動量の「飽和」をスラスタで捨てる運用も含め、`hardware/aerospace/avionics-gnc.md` の姿勢制御アクチュエータの物理そのものである。

### 4. 単振動・減衰・共振 (harmonic oscillation, damping, and resonance)

安定な平衡点のまわりでは、復元力は変位に比例する(§5 で見るとおり、これは近似ではなくテイラー展開の1次項である)。線形復元力だけの系が**単振動 (simple harmonic motion)** を生む。

```text
m·ẍ + kx = 0  ⟹  x(t) = A·cos(ω₀t + φ),  ω₀ = √(k/m)
振幅によらず周期一定 (等時性) — 振り子時計・水晶振動子が時間標準になれる理由
エネルギー: ½mv² と ½kx² の間を往復し、和 E = ½kA² は一定
```

現実には摩擦・空気抵抗が速度比例の減衰項を加え、外力が駆動項を加える——`m·ẍ + c·ẋ + kx = F(t)`。これは数学シリーズ ODE 文書 §3 の標準形 `ẍ + 2ζω₀ẋ + ω₀²x = 入力` そのものであり、**過減衰・臨界減衰・不足減衰の分類、共振、Q = 1/2ζ の全解析がそのまま適用される**——本稿で再導出はしない。強調すべきは対応の物理的な向きである: ODE 文書の対応表(質量 m ↔ インダクタンス L、摩擦 c ↔ 抵抗 R、ばね k ↔ 1/C)により、本節の機械振動は `../electromagnetism/circuit-theory.md` §5 の直列 RLC 共振と**同一の方程式の二つの顔**であり、機械系の直観と回路の解析道具は双方向に移送できる。機械側での現れは: 車のサスペンション(ばね上質量の ζ を臨界減衰近くに設計する——ダンパの死んだ車が揺れ続けるのは ζ が落ちたから)、建物・橋・ロケット機体の構造共振(駆動周波数が固有振動数を横切るときの増幅、タコマ橋の教訓)、そして制御系のアクチュエータ帯域を制限する機構共振である。共振は敵だけではない——振動式ジャイロ(MEMS)や超音波モータは高 Q の機械共振を精度と効率の源として使う。

### 5. 振り子と安定性 — 倒立振子へ (pendulum, stability, and the inverted pendulum)

長さ L の振り子の運動方程式は厳密には非線形である。

```text
θ̈ + (g/L)·sin θ = 0
平衡点: θ = 0 (真下) と θ = π (真上) — sin θ = 0 の解
θ = 0 まわり: sin θ ≈ θ     ⟹ θ̈ = −(g/L)θ    — 単振動 ω₀ = √(g/L)
θ = π まわり: sin(π+δ) ≈ −δ ⟹ δ̈ = +(g/L)δ    — 指数発散 δ ~ e^{t/τ}, τ = √(L/g)
```

これは ODE 文書 §4 の**線形化 → 固有値 → 安定判別**の最小の実例である。同じ方程式・同じ手続きで、符号1つが運命を分ける——真下の平衡は**安定 (stable)**(ずれると復元力が戻す。固有値は純虚数、摩擦を足せば左半平面)、真上は**不安定 (unstable)**(ずれは時定数 τ で指数的に成長する。固有値の一方が正の実軸上)。物理的には、安定平衡はポテンシャル U(θ) の谷、不安定平衡は山の頂であり、§4 の振動は「谷の底の曲率 U''」が決める普遍現象だったのである。

不安定側の**倒立振子 (inverted pendulum)** が現代制御の看板問題である理由は、この時定数にある——放置すれば e^{t/τ} で倒れる系を、τ より十分速く測って押し返すフィードバックだけが直立させられる。制御なしには1秒も立たないが、制御があれば立つ——プラントの不安定性をセンサと計算で買い戻す構図が、そのまま実システムに現れる: セグウェイとヒューマノイドの直立(倒立振子の安定化、`hardware/robotics/control-systems.md` の LQR の典型適用先)、二足歩行の線形倒立振子モデル(LIPM——時定数 √(z_c/g) ≈ 0.3 s が歩行制御の要求速度を決める、`hardware/robotics/locomotion-manipulation.md`)、そして推力偏向で立てるロケット——垂直着陸する Falcon 9 は、空力的に不安定な倒立振子を TVC とグリッドフィンで実時間安定化する制御問題である(`hardware/aerospace/spacex-reusability.md`)。

## 工学への接続 (Engineering Connections)

- **制御工学の「プラント」の正体**: 状態 (x, v) の2階 ODE (§1)、姿勢まわりの回転動力学 (§3)、平衡点線形化 (§5) ——現代制御の状態空間モデル `ẋ = Ax + Bu` は、本回の力学を線形化して行列に詰めたものである。極配置・LQR・MPC が動かすのはこの A・B の中身にほかならない。
- **ロケットの飛行は本回の総集編**: 並進は F = ma + ツィオルコフスキー (§2)、姿勢は剛体回転とジャイロ効果 (§3)、着陸は不安定平衡の実時間安定化 (§5)。Δv 収支・多段化・ホバスラングの各分析はすべてこの3節の上に立つ。
- **車両運動とエネルギー会計**: 駆動力と走行抵抗の釣り合い (§1)、衝突安全 = 運動量保存下でのエネルギー散逸設計、回生ブレーキ = ½mv² の回収 (§2)、サスペンション = 減衰比の設計 (§4)。EV の航続・効率の議論は仕事-エネルギー定理の応用問題である。
- **機構共振が制御帯域を制限する**: アクチュエータからセンサまでの機械系がもつ固有振動数 (§4) より上にループ帯域は伸ばせない——ロボットの関節剛性、ロケットの機体曲げモード、HDD のヘッド位置決めまで、この制約が制御設計の物理的天井を与える。
