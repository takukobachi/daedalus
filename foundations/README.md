# Foundations (基礎理論)

`hardware/`・`software/` の分析を支える数学・物理などの基礎理論 (foundations)。
既存の分析ドキュメントが暗黙に依拠している理論を、基礎から積み上げて明示的に
文書化する。分析から参照される資料であると同時に、体系立てて学び直すための
学習ノートでもある。

## 位置づけ

- `hardware/`・`software/` — 実在するシステムを**外から分析する**ドキュメント
- `foundations/` — その分析が**依拠する理論を基礎から積み上げる**ドキュメント

この対応を保つため、各文書には「Daedalus内の応用」セクションを置き、その理論が
支えている既存の分析ドキュメントへ相対リンクを張る。理論が分析から切り離されず、
分析側からも「なぜこの式が出てくるのか」を遡れるようにするための規約である。

## 構成

- `mathematics/` — 数学（線形代数、解析、確率・統計、フーリエ解析、離散数学 …）
- `physics/` — 物理学（力学、電磁気学、熱力学・統計力学、量子力学・固体物理 …）
- `information-theory/` — 情報理論（エントロピー、情報源符号化＝圧縮の下限、
  通信路容量＝通信の上限 …）。数学・物理以外の基礎理論系列の最初の1本
- `machine-learning/` — 機械学習（Transformer の数理、スケーリング則 …）。
  線形代数・確率・最適化・情報理論の合流点で、`software/ai/`・
  `software/ai/` の分析が依拠する理論側

分野内のサブディレクトリ・文書は、最初の1本を書くときに作成する（空の
プレースホルダは置かないという CLAUDE.md の規約）。将来的には計算理論・制御理論など、
他の基礎理論もこの直下に追加しうる。

## 学習の推奨順序

学び直しの観点での標準的な依存順序。詳細は各分野の README を参照。

1. 線形代数・微分積分 — すべての基礎。並行して進められる
2. 古典力学 — 微分積分の最初の応用先
3. 確率・統計、電磁気学 — それぞれ 1, 2 の上に立つ
4. フーリエ解析・信号処理 — 解析と電磁気（波動）の合流点
5. 情報理論 — 確率・統計の直接の応用先。圧縮・通信・符号の限界の言語
6. 熱力学・統計力学、量子力学・固体物理 — 上記すべてを前提とする到達点
7. 機械学習 — 線形代数・確率・最適化・情報理論の合流点。5 までを前提とする
   もう一つの到達点
