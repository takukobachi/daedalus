# CPUアーキテクチャ (CPU Architecture)

ソフトウェアの視点から見たCPU内部の分析。アーキテクチャ上の選択が性能や並行性にどう影響するかを扱う。

## トピック

- 命令セット (ISA) — RISC-V, x86, ARM
- パイプラインと分岐予測 (pipeline & branch prediction)
- キャッシュとメモリ階層 (cache & memory hierarchy)
- メモリ順序とアトミック (memory ordering & atomics)
- 割り込みと例外 (interrupts & exceptions)
- 仮想記憶・MMU・TLB (virtual memory)
- SIMD・ベクトル演算 (SIMD / vector)
