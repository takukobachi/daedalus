# 燃焼安定性 (Combustion Instability in Liquid Rocket Engines)

## 概要 (Overview)

液体ロケットエンジン開発の歴史で、最も多くのエンジンを壊してきた敵は、材料でも製造でもなく**燃焼不安定 (combustion instability)** である。燃焼室内の音響振動と熱発生が正のフィードバックで結合すると、圧力振動は数ミリ秒〜数百ミリ秒で壁面熱伝達を数倍に押し上げ、エンジンを焼損・破壊する。Apollo を月へ運んだ **F-1 エンジンは、この問題の克服だけに数年と1,000回超の実機燃焼試験を要した**——ロケット開発が「解析だけでは閉じない」ことの古典的証明である[^f1-history]。

本ドキュメントは、不安定の物理(**レイリー基準**: 熱発生が圧力振動と同位相なら増幅される)と3つの類型(チャギング/バジング/スクリーチ)を整理し、抑制手段(バッフル、音響キャビティ、噴射器設計)の設計論理を解剖する。そのうえで、Merlin/Raptor の文脈——多発クラスタ化という「中型エンジンを多数」戦略が安定性問題に与える利点、FFSC のガス-ガス噴射が持つ安定上の性質、そして McGregor の全数試験(`spacex-manufacturing.md`)が安定性保証で果たす役割——を分析する。分析深度は Level 3。

> 前提: エンジンサイクルと燃焼室の基本は `spacex-rocket-engines.md`、音響と共振の一般論は `../../foundations/physics/classical-mechanics/newton-laws-oscillations.md` の振動論。

## 方法論 (Methodology)

- 不安定を「**音響系(燃焼室・供給系)と熱発生の結合振動**」として定式化し、レイリー基準を分析の軸に置く。
- 周波数帯で3類型(チャギング/バジング/スクリーチ)に分け、それぞれ結合する系(供給系・構造・室内音響)と対策を対応づける。
- F-1 の開発史を一次資料(NASA 技術史・標準文献)で追い、「動的安定性の実証」という方法論の成立を読む。
- SpaceX 固有の情報は公開情報が限られるため、確実な公開事実(エンジン構成・試験体制)からの構造的な推論であることを明示して扱う。

## 発見事項 (Findings)

1. **不安定の本質はレイリー基準にある。** 「熱発生の揺らぎが圧力振動と同位相なら振動は成長し、逆位相なら減衰する」——1878年にレイリーが定式化した条件が、今日も設計の出発点である[^rayleigh]。燃焼室は高エネルギー密度の音響共鳴器であり、燃焼はその中の「増幅器」になりうる。
2. **周波数帯が犯人を教える。** 低周波(数十 Hz 級)のチャギングは供給系との結合、中間周波のバジングは供給系・構造との複合、高周波(数 kHz 級)のスクリーチは**燃焼室の音響モード**(接線・半径・縦)との結合である。高周波が最も破壊的で、壁面熱流束を数倍化しミリ秒〜秒オーダーでエンジンを破壊する[^sp194]。
3. **F-1 は「試して壊して直す」で解いた。** 1960年代の解析力では接線モード不安定を予測できず、Rocketdyne/NASA は**爆薬で人工的に擾乱を与えて減衰を確認する「ボム試験」**という動的安定性実証法を確立、噴射器バッフルの形状を1,000回超の実機試験で反復した[^f1-history][^sp194]。SpaceX の fly-fail-fix(`spacex-starship-superheavy.md`)は、実はこの伝統の高速化と読める。
4. **対策は「音を殺すか、位相をずらすか」。** バッフル(接線モードの分断)、音響キャビティ/レゾネータ(特定周波数の吸収)は音響系側への介入、噴射器の微粒化・混合設計は熱発生側の位相・分布への介入である。
5. **大きな燃焼室ほど危ない——多発クラスタの隠れた利点。** 不安定の主戦場である接線モードは燃焼室径で周波数が決まり、大径室ほど低周波化して燃焼の応答帯域と重なりやすい。F-1(単室・巨大)が苦しんだ問題を、SpaceX は**中型エンジンの多数クラスタ**(9基/33基)で構造的に回避している——「量産できるサイズ」の選択(`spacex-manufacturing.md`)は、安定性の面でも合理だった。
6. **FFSC のガス-ガス噴射は安定側に働く。** Raptor は両推進剤をプリバーナで気化してから主燃焼室へ噴く(`spacex-rocket-engines.md`)。液滴の微粒化・蒸発という**時間遅れの大きい過程**が主燃焼室からほぼ消えるため、熱発生の応答が速く一様になり、位相遅れ由来の結合が起きにくい——FFSC の複雑さが買っている安定性上の利得である[^gas-gas]。
7. **安定性は「証明」ではなく「実証」で保証される。** 現代でも高周波不安定の完全予測は難しく、保証の実体は試験にある。全エンジンを実燃焼させる McGregor の受入試験体制(`spacex-manufacturing.md`)は、製造品質と同時に**個体ごとの燃焼健全性**のゲートとして機能する。

## アーキテクチャ (Architecture)

### 不安定のループ (The Feedback Loop)

```
        ┌─────────── 音響系 ───────────┐
        │  燃焼室のモード(接線/半径/縦)  │
        │  供給系配管の固有振動          │
        ▼                              │
   圧力振動 p'                          │
        │                              │
        ▼                              │
   燃焼への影響 ── 噴射流量の変動        │
        │          微粒化・蒸発の変動    │
        │          混合・化学の変動      │
        ▼                              │
   熱発生の揺らぎ q' ───────────────────┘
        (エネルギー供給)

   レイリー基準:  ∮ p'·q' dt > 0  → 振動は成長(不安定)
                 ∮ p'·q' dt < 0  → 減衰(安定)
   p' と q' の位相関係が全てを決める[^rayleigh]
```

### 3類型 (The Three Regimes)

| 類型 | 周波数帯 | 結合する系 | 主対策 |
|---|---|---|---|
| **チャギング (chugging)** | ~数十 Hz | 供給系(配管・ポンプ)と燃焼室の圧力 | 噴射器圧力降下を大きく取る(供給系を「硬く」する)、ポゴ対策と共通(`rocket-structures-tanks.md`) |
| **バジング (buzzing)** | 中間帯 | 供給系・噴射器の局所振動 | 噴射器設計、配管の音響設計 |
| **スクリーチ (screech)** | ~数 kHz | **燃焼室の音響モード**(特に接線) | バッフル、音響キャビティ、噴射パターン[^sp194] |

- **噴射器圧力降下 (injector ΔP) の意味**: 噴射器前後の圧力差が大きいほど、室圧の揺らぎが流量に伝わりにくい(供給系と燃焼室が疎結合になる)。安定性の古典則「ΔP は室圧の 15–20% 以上」は、深いスロットリング時に室圧とともに ΔP が落ちて**低スロットルほど不安定に近づく**という、着陸バーン(`spacex-reusability.md`)に直結する制約を生む。

### 燃焼室の音響モード (Chamber Acoustic Modes)

```
   縦モード (longitudinal)   半径モード (radial)    接線モード (tangential)
   ←──→ 軸方向の定在波      ◎ 中心↔壁の振動       ↻ 周方向に回る/立つ波
                                                  ── 最も危険。回転波は
                                                     壁面熱流束を局所的に
                                                     数倍化し焼損させる
```

- 接線1次モードの周波数は概ね `f ≈ 0.59·a/D`(a: 音速, D: 室径)。**室径が大きいほど低周波**になり、微粒化・蒸発・混合の特性時間と重なって結合しやすくなる——F-1(D ≈ 1 m 級)が接線モードに苦しみ、小径多数のクラスタが構造的に有利になる理由がこの1式に凝縮されている。

## 技術詳細 (Technical Details)

### F-1 の教訓 — 動的安定性という方法論 (The F-1 Campaign)

- **問題**: 開発初期の F-1 は全力燃焼中に自発的な接線モード不安定を起こし、数秒でエンジンを破壊した。当時の解析では発生条件を予測できなかった。
- **解法の転換**: 「不安定が起きないことを祈る」から「**擾乱を与えても減衰することを実証する**」へ。燃焼中の室内で小型爆薬を起爆し(ボム試験)、圧力スパイクが規定時間内(~1/10秒級)に減衰することを合格条件とする**動的安定性評価 (dynamic stability rating)** を確立した[^sp194][^f1-history]。
- **ハードウェアの解**: 噴射器面に放射状の**バッフル**を立てて接線モードを分断し、噴射孔パターン・衝突角を系統的に変えた実機試験を1,000回超反復。最終形は「擾乱を与えても確実に減衰する」ことを実証して有人飛行に進んだ[^f1-history]。
- **現代への遺産**: (1) 安定性は設計値ではなく**実証項目**である、(2) 音響系への介入(バッフル・キャビティ)は解析が不完全でも効く頑健な対策である、(3) 大量の実機試験を許す試験場と予算が、そのまま開発能力である——McGregor の試験体制はこの系譜上にある。

### 抑制手段の設計論理 (Suppression Devices)

- **バッフル (baffles)**: 噴射器面から燃焼室へ突き出す仕切り板。接線モードの粒子速度が最大になる領域を物理的に分断し、モードの成立自体を妨げる。確実だが、冷却が難しく重量・熱負荷の代償がある。
- **音響キャビティ/レゾネータ (acoustic cavities)**: 燃焼室壁の共鳴空洞(ヘルムホルツ共鳴器・1/4波長管)で特定周波数のエネルギーを吸収する。バッフルより軽いが、狙った周波数にしか効かない——運転域が広い(深いスロットリングをする)エンジンでは設計が難しくなる。
- **噴射器そのものが第一の対策**: 微粒化・混合の空間分布と時間応答が熱発生の位相を決める。同軸スワール型・衝突型などの噴射素子の選択と配列が、後付けデバイスより根本的な安定性設計である。ロシア系エンジン(RD-170/180 系)が高室圧で安定を成立させてきた実績は、噴射器設計の蓄積によるところが大きい[^sp194]。

### SpaceX の文脈 — 構造的回避と試験による保証 (The SpaceX Context)

公開情報が限られる領域のため、確実な事実からの構造的推論として整理する:

- **中型×多数という回避**: Merlin(海面推力 ~845 kN)も Raptor(~2,750 kN)も、F-1(~6,770 kN)級の単室巨大化を避けている。理由の第一は量産性(`spacex-manufacturing.md`)だが、室径を抑えることは接線モード周波数を高く保ち、最も危険な不安定域から距離を取ることでもある。
- **ガス-ガス噴射の利得**: FFSC の主燃焼室には両推進剤が気体で入る。液体噴流の微粒化・液滴蒸発という遅れ要素——スクリーチの位相条件を作る主犯——が消えるため、燃焼応答は速く分布は一様になる。ガス-ガス燃焼の安定上の優位は燃焼研究でも指摘されており、FFSC の開発難度(2つのプリバーナ)と引き換えに得ている性質である[^gas-gas]。
- **深いスロットリングとの緊張**: 着陸バーン(`spacex-reusability.md`)は室圧を大きく下げ、噴射器 ΔP 比を悪化させる——スロットリング能力と安定余裕は本質的にトレードオフであり、Merlin の深絞り・再着火の実績は、この領域の設計・試験の蓄積を意味する。
- **全数試験という保証**: 不安定は個体差(製造ばらつき・噴射器の微小差)に敏感でありうる。全エンジンの受入燃焼試験(McGregor)は、安定性を**個体ごとに実測で確認する**体制として、F-1 の動的安定性実証の思想を量産に埋め込んだものと読める。

## 信頼性考察 (Reliability Considerations)

> 本分野の「セキュリティ考察」は、燃焼安定性では**開発リスクと保証の方法**として読み替える。

- **予測の限界を認める設計**: 高周波不安定は今日でも第一原理からの完全予測が難しい。信頼性は「不安定にならない設計の証明」ではなく、**マージン(ΔP・モード分離)＋頑健な抑制デバイス＋実機実証**の三層で構成するのが現実解である。
- **運転域の端が危ない**: 定格点で安定でも、始動・停止の過渡、深いスロットリング、推進剤温度の端(サブクール条件)で安定余裕は変わる。再使用エンジンは毎飛行でこれらの過渡を反復するため、**運転域全体での安定実証**が使い捨て時代より重い要求になる。
- **クラスタの新しい問い**: 33基が至近距離で燃える Super Heavy では、単体で安定なエンジンが、隣接エンジンの音響・排気と結合しないか——多発化は単室巨大化の問題を回避する一方、**エンジン間結合**という新しい検証項目を生む(飛行試験での多数基同時燃焼データの価値がここにもある)。

## 結論 (Conclusions)

燃焼不安定は、燃焼室という高エネルギー密度の音響共鳴器に「位相」という一見か細い条件で火が付く現象であり、レイリー基準の単純さと裏腹に、その予測は今日も工学の最前線にある。F-1 が残した最大の遺産はバッフルという部品ではなく、**「擾乱を与えて減衰を実証する」という保証の方法論**だった。

SpaceX はこの問題に対し、正面からの解析勝負ではなく構造的な回避と実証で臨んでいる——室径を抑えた中型エンジンの多数クラスタ、液滴の遅れを消すガス-ガス噴射(FFSC)、そして全数受入燃焼という個体実証。エンジンサイクル(`spacex-rocket-engines.md`)・製造戦略(`spacex-manufacturing.md`)・再使用の深絞り要求(`spacex-reusability.md`)がすべてこの一点で交差しており、燃焼安定性は「SpaceX がなぜその設計を選んだか」を裏側から説明する補助線である。
