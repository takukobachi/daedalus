# 電気自動車の基礎工学 (Electric Vehicle Fundamentals)

## 概要 (Overview)

電気自動車 (EV, electric vehicle) は、内燃機関 (ICE, internal combustion engine) の「燃料を燃やして得た熱で動く」仕組みを、「電池に蓄えた電気で動く」仕組みへ置き換えた乗り物である。中核は3つの電気部品——**電池 (battery)・電力変換器 (power electronics / inverter)・電動機 (electric motor)**——と、それらを管理する **BMS（電池管理）と熱マネジメント**である。

EV の本質は、自動車を**エネルギー貯蔵・電力変換・制御の問題**として捉え直すことにある。ICE が機械（ピストン・変速機・排気）の塊だったのに対し、EV は電気とソフトウェアの比重が大きい。本ドキュメントは、EV パワートレインを構成要素に分解し、各要素の原理と設計トレードオフ（エネルギー密度 vs コスト、効率 vs 重量、充電速度 vs 電池寿命）を Level 3 で整理する。後続の**テスラ深掘り**（バッテリ/4680・パワートレイン・E/E アーキ・製造）の共通土台とすることを狙う。

> 既存の `../in-vehicle-networks.md`（車載ネットワークと ECU）・`../functional-safety-iso26262.md`（機能安全）が「制御と通信」を扱うのに対し、本章は「電動化そのもの（エネルギーと動力）」を扱う。原理は EV 工学の標準教科書（Husain, Ehsani ほか）を一次資料とする（CLAUDE.md「Source Hierarchy」: 原理は教科書/査読/標準を優先）。

## 方法論 (Methodology)

- EV パワートレインを **(1) 貯蔵（電池）→ (2) 変換（インバータ）→ (3) 動力（モータ）→ (4) 回生（regen）→ (5) 管理（BMS・熱）** の5機能に分解し、各機能の原理・指標・トレードオフを対応づける。
- 各要素を ICE の対応物と対比し、「電動化で何が変わるか」を明確にする（変速機の消失、瞬時トルク、回生、エネルギー密度の壁）。
- 電池は **セル→モジュール→パック**の階層で捉え、化学（NMC/LFP）と形状（円筒/角形/ラミネート）のトレードオフを示す。
- 充電を **電力 (kW) 律速の問題**として定式化し、AC 普通充電と DC 急速充電、400V/800V を比較する。
- 数値は代表値・標準（SAE/IEC/ISO）と教科書に基づき桁感を優先する。安全は ISO 6469 等の枠組みで扱う。

## 発見事項 (Findings)

1. **電池が心臓であり制約でもある。** EV の航続・コスト・重量・寿命・安全のほぼすべてが電池に支配される。ガソリン（~12,000 Wh/kg）に対しリチウムイオン電池は ~150–300 Wh/kg と**エネルギー密度で約2桁劣る**——この差が EV 設計の根本制約。
2. **効率では EV が圧勝。** モータ＋インバータの効率は ~90% 級で、タンク→車輪効率は EV ~77% 前後に対し ICE は ~20–30%。エネルギー密度の不利を、**高効率と回生**で相当程度埋める。
3. **モータは瞬時トルク・広い回転域・回生が可能。** 低速から最大トルクを出せ、変速機をほぼ不要にする。逆回転で**発電機**になり、減速エネルギーを回収できる。
4. **電力変換器（インバータ）が性能の鍵。** 直流電池と交流モータを橋渡しし、スイッチング素子（IGBT / SiC MOSFET）の損失が効率と航続に直結する。
5. **充電は「電力 (kW)」の問題。** 同じ電池でも投入できる kW が大きいほど速く充電できる。車載充電器による AC は遅く（数 kW〜十数 kW）、DC 急速充電は数十〜数百 kW。**電池の C レートと熱**が上限を決める。
6. **BMS と熱マネジメントが安全と寿命を作る。** セル電圧・温度の監視、セル間バランス、SoC/SoH 推定、保護。リチウムイオンは**温度に敏感**で、熱暴走 (thermal runaway) を防ぐ熱設計が安全の核心。
7. **電圧アーキテクチャが充電と効率を左右する。** 400V が主流だが、**800V 化**で同電流でも電力を倍化し急速充電と効率を改善できる（代償は部品コスト・絶縁）。

```
                 ┌──────────────── 高電圧 DC バス ────────────────┐
                 │                                               │
   ┌─────────┐   │   ┌──────────┐   ┌──────────┐   ┌─────────┐   │
   │ 電池パック │──┼──▶│ インバータ │──▶│  モータ   │──▶│ 減速ギア │──▶ 車輪
   │ (Battery) │◀─┼───│ (DC→3φAC) │◀──│ (回生で   │   │ + デフ  │   (駆動)
   │  ~400/800V│   │   │ PWM 制御  │   │  発電機に) │   └─────────┘
   └─────────┘   │   └──────────┘   └──────────┘
        │        │        │
        │        │   ┌────────────┐  ┌──────────────┐
        │        └──▶│ DC-DCコンバ │─▶│ 12V系/補機    │（灯火・制御・空調等）
        │            │ (HV→12V)   │  └──────────────┘
        │            └────────────┘
        │        ┌──────────────┐
        └───────▶│ 車載充電器 OBC │◀── AC 普通充電（系統 AC→DC）
        │        └──────────────┘
        └──────────────────────────◀── DC 急速充電（充電器側で DC 直結）
```

| 要素 | 役割 | ICE の対応物 |
|---|---|---|
| 電池パック (battery pack) | エネルギー貯蔵 | 燃料タンク |
| インバータ (inverter) | DC→交流変換・トルク制御 | （なし / ECU + 点火） |
| モータ (motor) | 電気→機械（＋回生で逆） | エンジン |
| 減速ギア (reduction gear) | 回転数/トルク整合 | 変速機（EV は単段が多い） |
| DC-DC コンバータ | 高電圧→12V 補機電源 | オルタネータ |
| 車載充電器 (OBC) | AC→DC 充電 | （なし） |
| BMS / 熱マネジメント | 電池の監視・保護・温調 | エンジン冷却＋ECU |

### 電池の階層 (Cell → Module → Pack)

```
  セル (cell)        モジュール (module)        パック (pack)
  ┌──┐             ┌──┬──┬──┬──┐            ┌──────────────┐
  │  │  × 直列/並列  │  │  │  │  │  × 直列/並列 │ モジュール群    │
  │  │  ─────────▶ │  │  │  │  │  ─────────▶ │ + BMS + 冷却   │
  └──┘             └──┴──┴──┴──┘            │ + 筐体・保護     │
  ~3.2–3.7V        数十V                    └──────────────┘
                                            数百V / 数十kWh
```

- **直列 (series)** でセルを繋ぐと**電圧**が上がり、**並列 (parallel)** で繋ぐと**容量 (Ah)** が増える。
- パックのエネルギー `[kWh] = 電圧[V] × 容量[Ah] / 1000`。
- 近年は**モジュールを省いてセルを直接パックに収める** cell-to-pack（CTP）/構造一体化の流れがあり、テスラの構造バッテリ（後述の深掘り）もその一例。

### セル形状 (Cell Formats)

| 形状 | 特徴 | 採用例 |
|---|---|---|
| **円筒 (cylindrical)** | 量産容易・堅牢・標準化（18650/21700/4680） | テスラ、汎用 |
| **角形 (prismatic)** | 体積効率良・剛性高 | 多くの中国/欧州メーカ、LFP |
| **ラミネート (pouch)** | 軽量・形状自由・冷却面大、膨張対策要 | 一部 OEM |

## 技術詳細 (Technical Details)

### 1. 電池セル — 化学とトレードオフ (Battery Chemistry)

リチウムイオン電池は、**正極 (cathode)・負極 (anode)・電解質 (electrolyte)・セパレータ**から成り、Li⁺ が正負極間を移動して充放電する。性能は主に**正極材**で決まる。

| 正極 | 略号 | エネルギー密度 | コスト/安全/寿命 | 用途 |
|---|---|---|---|---|
| ニッケル系 | **NMC** (Ni-Mn-Co) | 高い | コバルト高価、熱安全はやや劣る | 長距離 EV |
| ニッケル系 | **NCA** (Ni-Co-Al) | 高い | 高出力、テスラが採用 | 長距離・高性能 |
| リン酸鉄 | **LFP** (LiFePO₄) | 低め | **安価・安全・長寿命**、低温やや不利 | 標準/廉価 EV、定置 |

- **トレードオフの核心**: NMC/NCA は**航続（エネルギー密度）**、LFP は**コスト・安全・寿命**。コバルト削減（高 Ni 化・LFP 化）が業界トレンド。
- 負極は黒鉛 (graphite) が主流で、**シリコン (Si) 添加**で容量を上げる試みが進む。
- 指標: エネルギー密度 (Wh/kg, Wh/L)、**C レート**（充放電速度。1C＝1時間で満充放電）、サイクル寿命、作動電圧 (~3.2–3.7V)。

### 2. 電動機 — PMSM と誘導機 (Electric Motors)

EV 用モータの主流は2種ある。

| 方式 | 原理 | 長所 | 短所 |
|---|---|---|---|
| **永久磁石同期機 (PMSM)** | 回転子に永久磁石、固定子の回転磁界に同期 | **高効率・高トルク密度**（特に低中速） | 磁石（希土類）が高価、高速で逆起電力対策要 |
| **誘導機 (induction, IM)** | 回転子に電流を誘導し回す（磁石不要） | 磁石不要・堅牢・高速域で有利 | 効率・トルク密度はやや劣る |

- **瞬時トルク**: 電動機は停止状態から最大トルクを出せるため、EV は変速機をほぼ不要にし、加速が滑らか。
- **界磁弱め (field weakening)**: 高速域で逆起電力を抑え回転数を伸ばす制御。
- テスラのように**前後で PMSM と誘導機を使い分ける**（効率と性能の両取り）設計もある（深掘りで詳述）。

### 3. 電力変換器 — インバータと半導体 (Power Electronics)

インバータは**直流（電池）を三相交流（モータ）へ変換**し、PWM（パルス幅変調）で電圧・周波数を制御してトルクと回転数を操る。心臓部はスイッチング半導体である。

| 素子 | 特徴 | 効果 |
|---|---|---|
| **IGBT**（シリコン） | 成熟・安価、スイッチング損失やや大 | 従来の標準 |
| **SiC MOSFET**（炭化ケイ素） | 高速・低損失・高温/高電圧に強い | **効率↑→航続↑、800V 化に好適**（コスト高） |

- SiC 採用で**インバータ損失を低減**し、同じ電池で航続を伸ばせる。テスラ Model 3 が量産車で先駆けて SiC を採用した。
- 周辺に **DC-DC コンバータ**（高電圧→12V 補機）と **車載充電器 (OBC)**（AC→DC）が付く。これらを**一体化（パワーエレクトロニクス統合）** して小型軽量化する流れがある。

### 4. 回生ブレーキ (Regenerative Braking)

減速時にモータを**発電機**として働かせ、車両の運動エネルギーを電気に戻して電池へ充電する。EV 固有の効率源である。

- **ブレンディング (blending)**: 回生だけでは止まりきれない/低速・低 SoC で効かないため、摩擦ブレーキと協調制御する。
- **ワンペダル走行 (one-pedal driving)**: アクセルを緩めるだけで強い回生減速をかける運転様式。市街地走行の効率を大きく改善する。
- 限界: 高 SoC（満充電近く）では受け入れられず、低温でも制限される。

### 5. 充電 — 電力律速の問題 (Charging)

充電速度は**投入電力 (kW)** で決まり、`電力[kW] = 電圧[V] × 電流[A] / 1000`。

| 種別 | 経路 | 代表電力 | 律速 |
|---|---|---|---|
| **AC 普通充電 (L1/L2)** | 系統 AC → 車載 OBC で DC 化 | ~1.4–22 kW | **OBC 容量**（車載側） |
| **DC 急速充電 (DCFC)** | 充電器側で DC 化し電池へ直結 | ~50–350+ kW | **電池の C レート・熱・電圧** |

- 規格: AC は **SAE J1772 / IEC 62196**、DC 急速は **CCS・CHAdeMO・NACS（北米テスラ系）・GB/T**。
- **充電カーブ (charge curve)**: 高 SoC ほど電流を絞る（taper）必要があり、実用上は「10→80%」の時間が指標。
- **800V 化**: 同電流で電力を倍化でき、急速充電時間と配線損失を改善（代償はコスト・絶縁設計）。

### 6. BMS と熱マネジメント (Battery Management & Thermal)

- **BMS (Battery Management System)**: 全セルの電圧・温度・電流を監視し、(1) **セルバランシング**（直列セルの電圧ばらつき是正）、(2) **SoC/SoH 推定**（残量・劣化）、(3) **保護**（過充電・過放電・過熱・過電流の遮断）を担う。EV の安全と寿命の要。
- **熱マネジメント**: リチウムイオンは**約 15–35°C で最良**。液冷プレートでセルを冷やし／温め、ヒートポンプで空調と統合する。**プレコンディショニング**（急速充電前に電池を適温へ）で充電速度と寿命を守る。

### 7. ICE との効率比較 (Efficiency vs ICE)

```
  ICE:  燃料 100% ─▶ エンジン熱効率 ~20–30% ─▶ 変速・伝達損 ─▶ 車輪 ~20–30%
  EV:   電池 100% ─▶ インバータ+モータ ~85–90% ─▶ 減速ギア ─▶ 車輪 ~77%
        （＋回生で運動エネルギーを回収）
```

EV はエネルギー密度でガソリンに約2桁劣るが、**タンク→車輪効率で 2–3 倍優位**かつ回生で回収できるため、実用エネルギー効率は大きく上回る（ウェル・トゥ・ホイールは発電構成に依存）。

## 安全考察 (Safety Considerations)

> 本分野の「セキュリティ考察」を、EV では**電気安全・熱安全**として読み替える（`../functional-safety-iso26262.md` の機能安全と相補的）。

| ハザード | 機構 | 対策・標準 |
|---|---|---|
| **熱暴走 (thermal runaway)** | セル内部短絡・過充電・過熱で発熱が自己増殖、隣接セルへ**伝播 (propagation)** | 化学選択（LFP は熱安全に優れる）、セル間断熱、放熱経路、BMS 保護 |
| **高電圧感電** | 数百V の活電部・絶縁劣化 | **絶縁監視・HVIL（高電圧インターロック）**、衝突時の高電圧遮断（パイロ式遮断器） |
| **衝突安全** | パックの圧壊・短絡・漏液 | 構造保護（床下配置・剛性筐体）、クラッシュ時遮断、ISO 6469 / UN R100 |
| **充電時の事故** | 過電流・接触不良・発熱 | 規格化されたハンドシェイク（充電器⇄車）、温度監視、ロック機構 |

主な標準: **ISO 6469**（EV 電気安全）、**UN ECE R100**（高電圧安全）、**ISO 26262**（機能安全, `../functional-safety-iso26262.md`）、**SAE J1772 / IEC 62196**（充電）。

## 結論 (Conclusions)

電気自動車は、自動車を**エネルギー貯蔵・電力変換・電動機制御**の問題へと作り替えた。電池がエネルギー密度で約2桁の不利を負う一方、モータ＋インバータの高効率と回生がそれを相当程度埋め、変速機の消失と瞬時トルクが運転体験を変える。設計はどこまでも**電池を中心としたトレードオフ**——化学（NMC vs LFP）、形状、電圧（400V vs 800V）、半導体（IGBT vs SiC）、熱と安全——の最適化である。

この基礎の上に、**テスラ**は4つの層すべてで踏み込んだ最適化を行った。

1. **バッテリ/4680** — セル化学・形状（4680）と**構造一体化パック**でコストとパック効率を攻める。
2. **パワートレイン** — PMSM/誘導機の使い分け、**SiC インバータ**、ドライブユニット統合で効率と航続を取る。
3. **ソフト/E/E アーキ** — **集中型 E/E アーキテクチャと OTA** で「ソフト主導の車」を作る。
4. **製造/生産技術** — **ギガキャスト**と構造パックで車体製造そのものを単純化する。

次の深掘りでは、本章の各要素（電池・モータ・インバータ・パック・充電・熱）が、テスラの実装でどう先鋭化したかを、公式情報・分解調査・一次資料に基づいて見ていく。
