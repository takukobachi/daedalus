# 電気推進 — ホールスラスタとイオンエンジン (Electric Propulsion: Hall Thrusters & Ion Engines)

## 概要 (Overview)

化学ロケットの排気速度は、推進剤の化学結合エネルギーという物理的天井（実用上 v_e ~4.5 km/s 級）に縛られる。**電気推進 (electric propulsion, EP)** はこの天井を外す。エネルギー源（太陽電池）と推進剤を分離し、電力でイオンを加速することで、化学の**10倍近い排気速度**（Isp 1,500〜3,000 s 超）を実現する。代償は推力で、得られるのは mN 級の「そよ風」である。この「細く長く」の推進が、Starlink の数千機（[`starlink-satellite-bus.md`](starlink-satellite-bus.md)）の軌道上昇・維持・離脱を支え、深宇宙探査機の大 Δv ミッションを成立させてきた。

本ドキュメントは、電気推進の支配方程式（電力・推力・排気速度の三角関係）から始め、主要2方式である**ホールスラスタ**（Starlink が採用）と**グリッド式イオンエンジン**の物理と設計トレードオフを解剖する。寿命を決める浸食の問題、電源処理系 (PPU) という「もう半分」、そしてミッション設計（スパイラル軌道上昇）への含意までを扱う。分析深度は Level 3。

> 前提: ロケット方程式と Isp は [`../spacex-rocket-engines.md`](../spacex-rocket-engines.md)、軌道と Δv は [`../orbital-mechanics.md`](../orbital-mechanics.md)、E×B ドリフトの電磁気は `../../../foundations/physics/electromagnetism/` の系譜。

## 方法論 (Methodology)

- 電気推進を「**電力制限推進 (power-limited propulsion)**」として定式化し、F = 2ηP/v_e という基本トレードオフからすべての設計判断を導く。
- ホールスラスタとイオンエンジンを、加速機構（準中性プラズマ vs 静電グリッド）の違いとして対比し、Starlink がホール式を選ぶ理由を構造的に読む。
- 物理・設計論は標準教科書 (Goebel & Katz) を典拠とし、Starlink 固有の数値は SpaceX 公称値として明示する（[`starlink-satellite-bus.md`](starlink-satellite-bus.md) と共通の方針）。
- 実績はフライトヘリテージ（Deep Space 1、はやぶさ、Dawn、Psyche、Starlink 艦隊）で裏づける。

## 発見事項 (Findings)

1. **電気推進の本質は「エネルギー源と推進剤の分離」。** 化学推進は推進剤自身が燃料でありエネルギー源だが、EP は太陽からエネルギーを得て、推進剤は単なる**反動質量**になる。ゆえに v_e は化学エネルギー密度に縛られず、電圧で決められる。
2. **推力と Isp は電力を取り合う。** ジェットパワー P_jet = ½·ṁ·v_e² = ½·F·v_e より、**F = 2ηP/v_e** となる。同じ電力なら、Isp を上げるほど推力は下がる。「どちらも欲しい」は電力を増やすことでしか買えず、EP の設計はまず**電力収支の設計**である[^goebel]。
3. **ホールスラスタは「グリッドを捨てた」ことで量産に向く。** 磁場で電子を閉じ込め (E×B ドリフト)、準中性プラズマのまま加速するため、空間電荷制限（後述）を回避しつつ構造が単純になる。効率・Isp の頂点はイオンエンジンに譲るが、**推力密度・単純さ・コスト**で勝る。Starlink の選択はここにある[^goebel]。
4. **イオンエンジンは精密だが繊細。** 静電グリッドでイオンだけを引き出し加速する方式は Isp 3,000 s 超と高効率を達成するが、引き出せる電流が**空間電荷制限 (Child–Langmuir 則)** で頭打ちになり、推力密度が低い。グリッドの精密製造と浸食管理が高コストの源泉である。
5. **寿命は「浸食」との戦いである。** 加速したイオンの一部が放電室壁・グリッドを叩き削る。ホール式の壁浸食は**磁気シールディング**（磁力線の形状で壁面付近の電位・プラズマ接触を制御する設計）で桁違いに改善された。数万時間級の寿命が実証され、EP の適用範囲を広げた[^magshield]。
6. **PPU が「見えない半分」。** 太陽電池の不安定な低圧直流を、放電用高圧・各種磁気回路・中和器へ変換・制御する**電源処理装置 (PPU)** は、質量・コスト・故障率でスラスタ本体に匹敵する。Starlink 級の量産では、PPU の民生部品化・簡素化が事実上の競争力になる（[`../spacex-manufacturing.md`](../spacex-manufacturing.md) の削除哲学の適用先）。
7. **EP はミッション設計を変える。** mN 級推力では軌道遷移は**連続噴射のスパイラル**になり、数週間〜数ヶ月を要する。「時間を推進剤に換える」取引であり、商業衛星の軌道上昇（電気推進衛星は投入から運用開始まで数ヶ月）、Starlink の運用高度への自力上昇、深宇宙の大 Δv（Dawn は化学では不可能な Δv ~11 km/s を達成）を可能にした[^dawn]。

## アーキテクチャ (Architecture)

### 電力制限推進の三角関係 (The Power-Thrust-Isp Triangle)

```
           電力 P (太陽電池が供給)
              │  効率 η で
              ▼  ジェットパワーへ
      P_jet = ½ F v_e     →   F = 2ηP / v_e
              │
    ┌─────────┴─────────┐
    ▼                    ▼
  推力 F                Isp = v_e/g0
  (軌道遷移の速さ)       (推進剤の節約)
    └── 同じ P では両立しない ──┘

  例 (桁感): P = 5 kW, η = 0.5, Isp = 2,000 s (v_e ≈ 20 km/s)
             → F ≈ 0.25 N — 「1円玉数枚の重さ」で数百 kg を押す
```

- **化学との分業**: 化学推進は「重力損失と戦う離陸・短時間の大 Δv」（[`../orbital-mechanics.md`](../orbital-mechanics.md) のオーベルト効果が働く場面）、EP は「時間をかけてよい軌道上の大 Δv」。打ち上げはロケット、軌道上は EP という分業は物理的必然である。

### 2方式の対比 (Hall vs Gridded Ion)

| 観点 | ホールスラスタ | グリッド式イオンエンジン |
|---|---|---|
| 加速機構 | 準中性プラズマ内の電場（磁場で電子を閉じ込め） | 静電グリッド間でイオンのみ加速 |
| Isp 領域 | ~1,500–2,800 s | ~3,000–4,000 s 超 |
| 推力密度 | **高い**（空間電荷制限なし） | 低い（Child–Langmuir 則） |
| 構造 | **単純**（グリッドなし） | 精密グリッド（熱変形・浸食管理） |
| 効率 | ~50–60% | ~60–70% 超 |
| 代表例 | SPT-100 系, **Starlink**, PPE (Gateway) | Deep Space 1 (NSTAR), はやぶさ (μ10), Dawn |
| 向く用途 | **量産・軌道維持・上昇**（コスト重視） | 深宇宙・超高 Isp（推進剤最小化） |

### ホールスラスタの内部 (Inside a Hall Thruster)

```
        環状放電チャネル（断面図）
   ┌────────────────────────────┐
   │  陽極 (兼推進剤導入)  ←──── Kr/Ar/Xe ガス
   │    │                       │
   │    │  軸方向電場 E          │ 半径方向磁場 B
   │    ▼                       │ （磁気回路が形成）
   │  ●━━ 電子は E×B で周方向に ━━● ← 電子が「足止め」され
   │      ドリフト（ホール電流）      周回しながら中性ガスを
   │    │                       │   電離し続ける
   │    ▼                       │
   │  イオンは重く磁場に縛られず   │
   │  電場で軸方向へ一直線に加速 ─┼──→ 排気 (10–20 km/s 級)
   └────────────────────────────┘
        外部の中和器 (カソード) が電子を放出し
        排気ビームを電気的に中和（帯電防止）
```

- **要点**: 磁場は**電子だけ**を捕える（イオンはラーマ半径が大きく素通り）。足止めされた電子群が (1) 電離源、(2) 加速電場を支える空間電荷、の二役を務める。「グリッドの仕事をプラズマ自身にやらせる」設計である[^goebel]。

## 技術詳細 (Technical Details)

### 空間電荷制限 — イオンエンジンの天井 (Space-Charge Limitation)

グリッド式では、加速ギャップ中がイオンだけになるため、イオン自身の正電荷が後続イオンの進入を妨げる。単位面積あたりの電流は **Child–Langmuir 則** `j ∝ V^(3/2)/d²` で頭打ちになり、推力密度の上限を与える。ホール式が準中性（電子が混在）のまま加速することの価値は、この制限の**回避**にある。同じ開口面積でより大きな推力が出せ、衛星搭載面積という現実の制約に対して有利に働く。

### 浸食と磁気シールディング (Erosion & Magnetic Shielding)

- **機構**: 加速イオンの一部が放電チャネル壁（セラミック）に斜入射し、スパッタリングで削る。壁が痩せると磁気回路が露出し、寿命が尽きる。これが初期のホール式の寿命律速だった。
- **磁気シールディング**: 磁力線が等電位線とほぼ一致する性質を使い、壁面に沿う磁力線を「チャネル奥の低電位」につなぐよう磁気回路を設計する。壁面付近の電位勾配（イオンを壁へ向ける力）が消え、浸食が桁で減る。JPL らの研究で実証され、数万時間級の運用が視野に入った[^magshield]。
- **含意**: 寿命が「消耗部品の交換不能な宿命」から「磁場設計の変数」に変わったことが、EP を長期ミッション・大型輸送（Gateway の PPE 等）へ押し出した。

### 推進剤の選択 — 再訪 (Propellant Choice Revisited)

[`starlink-satellite-bus.md`](starlink-satellite-bus.md) で見た Xe→Kr→Ar の経済学を、物理側から補強する。

- **原子量の効果**: 同じ加速電圧なら v_e ∝ 1/√M（軽い原子ほど速い＝Isp は上がる）が、同じ電力での**推力は重い原子が有利**。また電離エネルギーは Ar > Kr > Xe で、軽い推進剤ほど電離に多くの電力を取られ効率が落ちる。
- **システムで吸収する**: アルゴンの物理的不利（電離コスト・低推力密度）は、放電設計の最適化と「大電力・長時間噴射を許すミッション設計」で補える。**推進剤単価と調達安定が支配的になる機数**では、物理の不利より経済の有利が勝つ。Starlink V2 Mini の公称値（170 mN / 2,500 s）はその成立を示す[^argon-ref]。

### PPU と系統設計 (Power Processing & System Design)

- **役割**: 太陽電池のバス電圧（数十〜百 V 級）から、放電用高圧（数百 V）、磁気回路・カソードヒータ・流量制御へ、複数系統の変換・シーケンス制御を行う。始動（カソード加熱→放電点火）と故障保護（放電振動・逆流への対応）も担う。
- **質量・コストの実像**: スラスタ・PPU・推進剤系・配線を合わせた**システム質量**で化学推進と比較しなければならない。小型衛星で EP が常に勝つわけではない理由がここにある（ミッション Δv が小さいと、PPU の固定質量が利得を減らす）。
- **量産の視点**: Starlink は「スラスタ＋PPU＋タンク」を衛星ごとに1式積む。数千機分の PPU を民生パワーエレクトロニクスの部品と製造ラインで作ることは、宇宙用特注品の常識を崩す量産判断であり、[`../spacex-manufacturing.md`](../spacex-manufacturing.md) の哲学の衛星版である。

## 信頼性考察 (Reliability Considerations)

> 本分野の「セキュリティ考察」は、電気推進では**寿命保証と運用信頼性**として読み替える。

- **寿命試験のジレンマ**: 数万時間の寿命を地上実証するには文字どおり数年を要する。加速試験は浸食の物理（施設背圧の影響等）を歪めるため、**磁気シールディング等の物理的根拠＋部分試験＋軌道上データ**の組合せで保証する方向にある。Starlink 艦隊は、図らずも史上最大の EP 軌道上寿命データベースを生成している。
- **プルーム干渉**: 排気プラズマは太陽電池・光学面への付着や帯電を引き起こしうる。スラスタ配置とプルーム角の管理は衛星レイアウトの制約条件である。
- **単基故障の意味の違い**: 深宇宙機では EP 故障は致命的になりうる（Dawn は予備系で完走）。Starlink では艦隊冗長（[`starlink-satellite-bus.md`](starlink-satellite-bus.md)）が個体故障を吸収するが、**離脱能力の喪失**はデブリ問題に直結するため、「推進系が死んだ衛星の割合」が艦隊の環境責任の実効指標になる。

## 結論 (Conclusions)

電気推進は「化学より優れたロケット」ではない。**エネルギー源と反動質量を分離し、時間を推進剤に換える**、別種の推進である。F = 2ηP/v_e という単純な式が全設計を支配し、ホールスラスタはその式の中で「単純さと推力密度」を、イオンエンジンは「Isp の極限」を取った解として並び立つ。磁気シールディングが寿命を設計変数に変え、PPU の量産化がコストを崩したことで、EP は実験的装置から**インフラ**になった。

Starlink はこの転換の到達点である。かつて深宇宙探査機に1基ずつ丁寧に積まれた電気推進が、いまは週産数十基で製造され、数千基が自律運用される。ロケット編で見た「量産が性能を再定義する」構図（[`../spacex-manufacturing.md`](../spacex-manufacturing.md)）は、軌道の上でも同じように働いている。残る接続先は理論側であり、E×B ドリフトとプラズマ物理の基礎は `foundations/physics/electromagnetism/` の将来ロードマップ（プラズマ物理）に委ねる。
